
# Org Chart Inference Platform

An explainable organizational hierarchy inference platform
that predicts employee reporting relationships from
company and employee information.

## Project Objectives

- Generate 500+ synthetic companies.
- Generate realistic employee records.
- Preserve organizational ground truth.
- Infer employee-manager relationships.
- Assign confidence scores to predictions.
- Evaluate inference accuracy.
- Visualize organizational hierarchies.

## Technology Stack

- Python
- Pandas
- DuckDB
- Parquet
- NetworkX
- RapidFuzz
- Streamlit
- Plotly
- Pytest

## Running Locally

Install dependencies:

```bash
pip install -r requirements.txt
```

Start the application:

```bash
streamlit run app.py
```
